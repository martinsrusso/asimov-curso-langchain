# ASIMOV — Curso LangChain 1.0 na prática — Módulo MD-01

Este repositório contém o código da aula "Aplicações Inteligentes com IA" (módulo `MD-01`).

Estrutura principal:

- `main.ipynb` — notebook com exemplos e exercícios
- `src/` — código fonte do módulo
- `.env_exemplo` — arquivo de exemplo para variáveis de ambiente (não enviar o `.env` real)

Como usar

1. Crie um ambiente virtual e instale dependências:

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1  # Windows PowerShell
python -m pip install -r requirements.txt  # ou use pyproject.toml
```

2. Copie `.env_exemplo` para `.env` e preencha suas chaves de API.

3. Execute `main.ipynb` no Jupyter/VS Code.

Notas

- Não adicione seu `.env` no repositório. Use `.env_exemplo` como referência.
- Este repositório usará múltiplos módulos para o curso; mantenha cada módulo em pastas separadas.
